# Stein Bridge options

Every `-D` option the Bridge reads, generated by `./gradlew options` (`tools/OptionsDoc.java`) from the `*Options` classes.
Pass them to the JVM (`./gradlew runClient -Pstein.jvmArgs="-D..."`). Most are diagnostics, verification modes
(`*Check`) or kill switches of single optimizations; players never need them. Options taken out on purpose are
listed at the end.

## LensOptions

`dev.xavier.stein.bridge.lens.LensOptions`

- `-Dsteinlens.config=file`: reads another configuration file instead of config/steinlens.json (default: unset).
- `-Dsteinlens.diag.presetAtSec=S:P`: test, applies graphics slider position P after S seconds of play (default: unset).
- `-Dsteinlens.customItems=true|false`: overrides the file's custom items setting without saving (default: unset, the file decides).
- `-Dsteinlens.connectedTextures=true|false`: overrides the file's connected textures setting without saving (default: unset, the file decides).
- `-Dsteinlens.debug=true`: zoom state (every 2 s and on every change) and custom items lookups, recomputed choices and enchantment version steps (every 2 s) in the log (default: off).

## CoreOptions

`dev.xavier.stein.bridge.core.CoreOptions`

- `-Dsteinbridge.gfx=false`: the game draws with its own fixed-function pipeline instead of Stein GFX (default: Stein GFX). Without an OpenGL 4.1 core context the fixed-function pipeline is used anyway.
- `-Dsteinbridge.gfx.api=opengl|vulkan`: the graphics API Stein GFX draws with for this session, instead of the one saved in the video options (default: unset, the saved choice; OpenGL when there is none). Without Vulkan on the machine the game falls back to OpenGL.
- `-Dsteinbridge.gfx.vkGlSink=false` (diagnostics): with Vulkan, no hidden OpenGL context absorbs the OpenGL calls of mods that call it directly — such a call then aborts the game, which is how to find one (default: the context exists).
- `-Dsteinbridge.opt.noVsyncLatencyFix=true`: goes back to the usual VSync instead of adaptive VSync with a GPU fence per frame (default: off, the latency fix is on).
- `-Dsteinbridge.diag.background=true`: test bench only; the window appears minimized and without focus (default: off).
- `-Dsteinbridge.gfx.glDebug=true`: asks GLFW for an OpenGL debug context (default: off).
- `-Dsteinbridge.perf.timeSwap=true`: times the buffer swap and the event queue and prints the worst case and average per second (default: off).
- `-Dsteinbridge.perf.frameStats=true`: every 5 seconds, prints the frame count, the average, p50 and p99 frame times and the 1% low (the average FPS of the slowest 1% of frames), to compare the graphics APIs on the bench (default: off).

## EngineOptions

`dev.xavier.stein.bridge.engine.EngineOptions`

- `-Dsteinbridge.opt.noIdleLimit=true`: no frame limit while the game is idle (out of focus and title screen 30, Esc menu 60; default: limited).
- `-Dsteinbridge.diag.idleLimit=true`: keeps the idle frame limit on the test bench too, where `-Dsteinbridge.diag.background` turns it off so measurements run at full speed (default: off).
- `-Dsteinbridge.opt.vanillaActiveChunks=true`: turns the active-chunks bookkeeping optimisation off (default: on).
- `-Dsteinbridge.opt.checkActiveChunks=true`: runs both active-chunk paths every tick and compares the sets (default: off).
- `-Dsteinbridge.opt.vanillaChunkAt=true`: does the chunk lookup every frame instead of caching it per column (default: cached).
- `-Dsteinbridge.opt.vanillaCull=true`: uses the game's visibility search and chunk culling (default: Stein's).
- `-Dsteinbridge.opt.checkCull=true`: computes the visibility graph both ways and compares them (default: off).
- `-Dsteinbridge.opt.vanillaChunkHash=true`: restores the original chunk hash (default: Stein's).
- `-Dsteinbridge.opt.vanillaChunkArena=true`: one buffer per chunk, as in the game, instead of terrain per region; only matters without Stein GFX (default: regions).
- `-Dsteinbridge.opt.arenaPointers=true`: redoes the buffer bind and the 4 pointers on each terrain run instead of using the region's VAO; only matters without Stein GFX (default: the VAO).
- `-Dsteinbridge.opt.vanillaInfoFilter=true`: loops over the whole render-info list instead of the filtered copy (default: filtered copy).
- `-Dsteinbridge.opt.checkInfoFilter=true`: rebuilds the filtered copy on every use and compares it with the stored one (default: off).
- `-Dsteinbridge.visuals.keepChunks=N`: initial chunk keeping mode: 0 off, 1 memory, 2 disk (default: 0).
- `-Dsteinbridge.visuals.keepChunksMB=N`: initial size limit of the kept chunks in megabytes (default: 512).
- `-Dsteinbridge.visuals.keepDebug=true`: every 5 s, prints stored columns, bytes and what the disk has (default: off).
- `-Dsteinbridge.visuals.chunkUploads=N`: initial limit of chunk uploads per frame, 0 = no limit (default: 0).
- `-Dsteinbridge.visuals.waitNeighbors=true`: initially holds a chunk until its neighbours have arrived (default: off).
- `-Dsteinbridge.opt.vanillaChunkPrepare=true`: skips the chunk preparation (default: prepared).
- `-Dsteinbridge.opt.vanillaBfs=true`: uses the game's breadth-first visibility search (default: Stein's).
- `-Dsteinbridge.opt.checkBfs=true`: runs both searches and compares them (default: off).
- `-Dsteinbridge.opt.vanillaNearBuild=true`: builds everything adjacent to the player right away (default: Stein's order).
- `-Dsteinbridge.opt.vanillaArrivalSearch=true`: repeats the search on chunk arrival as the game does (default: Stein's).
- `-Dsteinbridge.opt.vanillaChunkThreads=true`: uses 2 chunk build threads, as in the game (default: off).
- `-Dsteinbridge.opt.chunkThreads=N`: number of chunk build threads (default: half the logical CPUs, between 2 and 8).
- `-Dsteinbridge.diag.terrainWatch=true`: every 5 s, prints the state of the terrain watchdog diagnostic (default: off).
- `-Dsteinbridge.opt.vanillaArmorGlint=true`: draws the armor glint piece by piece, as in 1.8.9 (default: Stein's).
- `-Dsteinbridge.gfx.debugGlint=true`: prints the armor glint replay diagnostic (default: off).
- `-Dsteinbridge.opt.vanillaArmorTexture=true`: computes the armor texture on every piece, as the game does (default: cached).
- `-Dsteinbridge.opt.vanillaSkinLoad=true`: loads skins as the original does (default: asynchronous).
- `-Dsteinbridge.opt.noSharedSkin=true`: one texture per waiting skin, as before the default skin was shared, for the A/B measurement (default: off, the waiting skins share one texture).
- `-Dsteinbridge.visuals.compactAngles=true`: initially uses the compact angle table (default: off).
- `-Dsteinbridge.visuals.directRender=true`: initially renders directly to the window (default: off).
- `-Dsteinbridge.visuals.glint=N`: initial enchantment glint mode: 0 on, 1 near only, 2 off (default: 0).
- `-Dsteinbridge.visuals.glintNear=N`: initial near-glint distance in blocks, parsed as a float (default: 16).
- `-Dsteinbridge.visuals.nametags=N`: initial maximum nametag distance in blocks, 0 = the game's (default: 0).
- `-Dsteinbridge.visuals.armor=false`: hides armor on entities; only the exact value `false` turns it off (default: on, armor shown).
- `-Dsteinbridge.visuals.fog=N`: initial fog mode: 0 normal, otherwise light or off (default: 0).
- `-Dsteinbridge.visuals.cloudHeight=N`: initial cloud height offset in blocks (default: 0).
- `-Dsteinbridge.oldAnimations=false`: turns all the old 1.7 animations off; only the exact value `false` does (default: on).

- `-Dsteinbridge.opt.vanillaClouds=true`: rebuilds the clouds every frame, as in 1.8.9 (default: Stein's cache).

- `-Dsteinbridge.opt.vanillaCraftInit=true`: restores the crafting search call, for A/B (default: skipped).

## Removed options

Written by hand (`./gradlew options` keeps this section as it is): options of earlier Bridge builds that are gone on
purpose. Passing them does nothing.

- `-Dsteinbridge.opt.warmUp=true`: drew an invisible fake player for the first seconds in a world, to compile the
  entity drawing code before a crowd arrives. It was off by default and measured no gain (the first arrival stayed
  cold in tick, network and names); `WarmUp` was removed.
- `-Dsteinbridge.diag.skip=armor,helditem`: the ablation test (skipped drawing armor or the held item). It changed what
  the player sees, so it was removed with its patcher rules.
- `-Dsteinbridge.gfx.core=...`: Stein GFX always draws in a core context now; without one the fixed-function pipeline
  is used (`-Dsteinbridge.gfx=false` picks it by hand).
- `-Dsteinbridge.gfx.trackedPassState=false`: went back to driver queries and `glPushAttrib` around each pass. The
  core context has neither, so the tracked pass state is always on.
- `-Dsteinbridge.gfx.terrain`, `.sky`, `.clouds`, `.worldExtras`, `.hand`, `.gui` (`=false`): each turned one part of
  the frame back to the game's own drawing. In a core context the game's fixed-function drawing does not exist, so
  Stein GFX always draws them; the whole fallback is `-Dsteinbridge.gfx=false`.
- `-Dsteinbridge.gfx.groupCache`, `.strictSegments`, `.skipRebind` (`=false`): internal switches of the deferred
  passes (state group cache, strict order in segments, skipping the rebinding of binding 0), now always on.
- `-Dsteinbridge.gfx.particleCapture=false`: kept the fast particle writing but drew the particles outside the
  recorded pass. `-Dsteinbridge.gfx.particles=false` still turns both off.
- `-Dsteinbridge.gfx.sessionLog=true`: printed the first draws of the extra recorded passes (sky, clouds,
  particles, world extras) with the state read.
